Export saved gaming tool data

Run this page at the original GitHub Pages address in the same browser you used for Goldspire Calendar, Trade Binder, Dungeon Crawler, War Tool, or the Scrabble tile drawer. It saves only those tools' known browser storage keys to a JSON file on your device.

The file can contain your notes, wants list, game progress, and battle history. Keep it private. The export page does not send it to a server. Party Invite and the Halloween planner stay at their original addresses and are not included.
