# Copy Rewrites — Daggerheart Resource Page

The resource page copy is clear, warm, and well-judged ("without the rulebook cliff," "Fear is not failure," "the sheet looks like a tax document with a sword"). The issues are **structural omissions**, not bad sentences.

## A. Add a closing CTA (Medium) → [BUG-03](../bugs/BUG-03-daggerheart-no-footer/report.md)
The page ends on "Go deeper only if it sounds fun" (official links) and then **stops** — no footer, no path back, no "claim a seat." A reassured player has nowhere to go.

**Add a closing band (new copy):**
> ## Reassured? Good. The hard part is over.
> You've done more prep than we asked for. Now the only step left is the fun one.
> **[ Claim a seat → ]**  ·  **[ Back to the Goldspire event ]**

(Point "Claim a seat" at the same destination as the event page CTA so it stays in sync.)

## B. Lead with the convert-line for tourists (Low)
The "Start Here" intro is good. Add the one sentence the Daggerheart-experienced visitor wants:
> *(append to the intro)* You don't need to have played Daggerheart before — if you know another RPG, you'll be up to speed in minutes; if you've never played anything, the table teaches as you go.

## C. Tiny consistency (Low)
- The important-note card ("not official Darrington Press programming") is well-placed and good practice — **keep it.**
- Mirror the event page's Twitter-card meta here (currently OG only) so shared links preview consistently. (Code task, see [C4](../04-code-qa/code-qa-report.md).)

## D. Optional voice top-up
This page is slightly *more* buttoned-up than the event page. A single corporate-satire aside in the hero would tie it to the brand without adding cliff:
> *(optional sub-line under the H1)* "Optional reading. Management has pre-approved your curiosity."
