GM goal

Build relationships between PCs.

GM notes

  • Script: Use the prompt bank and Connection Builder. Ask each player for at least one connection in quick mode. Save accepted, clarified, complicated, or passed results.
  • Process: character postcards, one anchor connection, one tension/trust connection, then one group memory.
  • Show players only the active prompt and permission language, not the whole GM prompt bank.
  • Checklist: At least one connection target per player; Connection Builder entries saved; Group memory asked if time allows; Ask one optional world-connection question per player if the table has energy.; Log answers as table-contributed canon when they point at a faction, NPC, or location.
