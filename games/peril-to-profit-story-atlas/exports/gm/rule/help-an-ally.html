Help an Ally

GM export - rule:help-an-ally

What it is

Spend Hope to add an advantage die to another PC's roll.

How it works

Use when the helper can describe real help in the fiction.

Step by step

  • Use when the helper can describe real help in the fiction.
  • Spend Hope, describe the help, and add the help die.
  • Return to the fiction with the concrete result, cost, or benefit.
