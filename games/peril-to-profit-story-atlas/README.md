# Goldspire Messengers GM Story Atlas

Open `index.html` through a local static server for the best browser behavior.
The site is also designed to keep core data inline for offline/local use.

## Contents

- `index.html` - interactive cinematic GM control room
- `pages/scenes/` - dedicated scene pages
- `pages/entities/` - dedicated wiki pages for NPCs, creatures, factions, companies, locations, items, clues, mechanics, and conditions
- `data/` - synced JSON source used by the site
- `assets/` - Image Gen raster outputs only; missing slots fail QA
- `obsidian_vault/` - packaged copy of the generated Obsidian vault
